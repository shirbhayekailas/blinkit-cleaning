## 🛠️ Features Included

1. **GST Standard Tax Invoicing**: Single line-item + Monthly consolidated invoices with Blinkit billing entity specs.
2. **Before vs After Photo Comparison**: Interactive slider for pitch-black floor vs scrubbed finish.
3. **QR Code Dark Store Check-In**: Printable store gate QR cards + supervisor camera scanner.
4. **Hindi Voice Typing**: Real-time speech-to-text for supervisor notes and defect logs.
5. **Night Multi-Store Route Map**: 1-click turn-by-turn Google Maps van navigation.
6. **FSSAI Hygiene Certificate**: Gold-bordered QA PDF certificate generator.
7. **Chemical Inventory & Stock Alerts**: Taski R2, Taski R7, Sodium Hypochlorite usage logs.
8. **Cleaner Staff Khata**: Daily wage calculation and advance payouts tracker.
9. **Desktop Standalone App**: Electron native desktop window (
pm run desktop).
10. **PWA & Offline First**: 100% operational offline in basement dark stores with automatic cloud sync.
